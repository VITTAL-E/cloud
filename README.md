# StratoOps Cloud & DevOps Website

HTML + CSS + vanilla JavaScript website converted from the Stitch screens.

## Pages
- index.html — Enterprise Cloud Migration
- home-2-cloud-native-sre.html — Cloud Native & SRE
- services.html
- case-studies.html
- technologies.html
- about.html
- contact.html

## Features
- Persistent light/dark theme toggle
- Persistent RTL/LTR toggle
- Working desktop navigation
- Responsive mobile navigation drawer
- Cross-page navigation for all `data-path` links
- Meaningful CTA routing
- Basic form validation and success feedback
- Original Stitch layouts/content preserved

## Run
Open `index.html`, or use a local server:

`python -m http.server 5500`

Then open `http://localhost:5500`.
