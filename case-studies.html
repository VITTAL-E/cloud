The Mission Bottleneck

Operating on aging on-premise mainframe partitions and monolithic Oracle RAC clusters across two private data centers, the bank faced quarterly release cycles that choked competitive velocity. An impending regulatory stress test (OCC & ECB compliance) required automated cross-region recovery with zero transaction loss, which their legacy stack could not deliver.

Pre-Cutover Friction

Release rate limited to once per 90 days. Batch reconciliation running over 14 hours each night with persistent ledger lockouts.

Target Architectural Mandate

Sub-30ms API latency, active-active multi-region failover, immutable GitOps deployment pipeline with verifiable audit trail.

We orchestrated a four-phase strangler-fig pattern, dissecting the monolith into 48 domain-driven microservices running on dual-region AWS EKS clusters. We deployed an active-active Aurora Global Database paired with multi-broker Kafka streaming clusters for bidirectional ledger reconciliation.
